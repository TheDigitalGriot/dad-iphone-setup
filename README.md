# Dad's iPhone Setup Guide

A friendly, interactive step-by-step web guide built to help my dad set up his new iPhone 15 after moving from a Samsung Android phone.

**Live site:** https://thedigitalgriot.github.io/dad-iphone-setup/

## What it covers

Ten plain-language steps:

1. Welcome and what you'll need
2. Installing Move to iOS on the Samsung
3. Powering on the iPhone, choosing language
4. Connecting to Wi-Fi
5. Face ID and passcode
6. Transferring data from Samsung
7. Apple ID setup (existing or new)
8. The remaining setup screens (Siri, Apple Pay, etc.)
9. The Home Screen — Android-to-iPhone differences
10. First things to try on day one

## How it works

Single self-contained HTML file. No external dependencies, no analytics, no build step. Open `index.html` in any browser, or visit the live site.

Designed for accessibility:

- Large fonts (19px+ body)
- High contrast
- Clear progress indicator
- Keyboard navigation (arrow keys)
- Works on phones, tablets, and desktops
